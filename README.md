# 🎬 Movie Recommendation System

A Python-based CLI app that recommends movies using the TMDB 5000 dataset.

## Features
- View top rated movies
- Filter movies by genre (Action, Comedy, Drama...)
- Get similar movie recommendations based on a title
- Search movies by language

## Tech Stack
- Python 3.11
- Pandas

## How to Run
```bash
pip install pandas
python3 recommender.py
```
## Dataset
Download from Kaggle: [TMDB 5000 Movies](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)
Place `tmdb_5000_movies.csv` in the root folder before running.
